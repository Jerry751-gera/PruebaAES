# Prueba Usuarios AES
Proyecto de API REST con Spring Boot que implementa seguridad AES y persistencia en Oracle.

## Características
* **CRUD Completo:** Gestión de usuarios y direcciones (Relación OneToMany).
* **Seguridad:** Contraseñas encriptadas mediante AES antes de guardarse en BD.
* **Documentación:** Swagger UI disponible en `/swagger-ui/index.html`.

## Tecnologías
* Java 17
* Spring Boot 4.0.2
* Oracle DB
* Maven
